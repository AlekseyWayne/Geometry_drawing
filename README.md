# Geometry Drawing — генерация чертежей GeoGebra через LLM

Проект автоматически переводит текст геометрической задачи на естественном языке
в команды GeoGebra с помощью YandexGPT (через OpenAI-совместимый API Yandex.Cloud),
а затем отрисовывает результат в браузере через Selenium и сохраняет построение в XML.

---

##  Как это работает

1. Пользователь задаёт текст геометрической задачи (строка `task` в скрипте).
2. Скрипт отправляет задачу в YandexGPT с большим системным промптом,
   который содержит:
   - жёсткие правила синтаксиса GeoGebra,
   - словарь разрешённых команд,
   - 7 паттернов типовых построений (отложить отрезок на луче, точка на заданном
     расстоянии, угол и биссектриса, перпендикулярность, угол заданной градусной
     меры, точки на одной прямой, луч как биссектриса).
3. Модель возвращает **только команды GeoGebra**, по одной на строку.
4. Selenium открывает [GeoGebra Classic](https://www.geogebra.org/classic),
   выполняет каждую команду через `ggbApplet.evalCommand()`.
5. Построение сохраняется в файл `my_drawing.xml`.

---

##  Структура кода

| Блок | Назначение |
|------|-----------|
| **1. Настройки Yandex API** | Чтение `YC_FOLDER_ID` и `YC_API_KEY` из переменных окружения |
| `get_geogebra_commands_from_yandex(task_text)` | Отправка задачи в LLM и парсинг ответа в список команд |
| **2. Текст задачи** | Переменная `task` — сама геометрическая задача |
| **3. Отрисовка в GeoGebra** | Selenium + `evalCommand()` + сохранение XML |
